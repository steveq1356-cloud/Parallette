Returns & exchanges

We stand behind every set we make. If something isn't right, we'll fix it.

30-day return window

If you're not happy with your order for any reason, contact us within 30 days of delivery and we'll arrange a return or exchange. Items must be in original condition.

How to start a return

  • Email hello@formparallettes.com with your order number and reason for return
  • We'll reply within 1 business day with a prepaid return label
  • Drop the package off at any USPS location
  • Refund is issued within 3–5 business days of us receiving the return

Defects & damage

If your order arrives damaged or with a manufacturing defect, we'll send a replacement immediately at no cost to you. Just send us a photo.

Custom orders

Because each set is made to order, we're unable to accept returns on custom color combinations that were not listed on the site. If there's a defect, that's always on us regardless.
